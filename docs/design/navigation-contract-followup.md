# 导航装配与管理契约补充

状态：已实现并通过本地四门和独立复核，2026-10-26。本轮以4f9da0e为基线，先核实三项报告，再按用户裁决修复，不修改真实账户、角色或导航记录。

## 裁决与根因

- H-1：空白名单使page不可创建属实，但/dashboard并非当前已注册页面，前端尚未实现；既有设计明确空列表不得创建不存在页面。用户裁决后续再接入页面。本期提供可信配置入口及明确未配置反馈，不关闭白名单或添加虚假页面。action必须隶属于真实page，myNavigation没有页面时为空属合理结果。
- M-1：DELETE只从path/query取输入，version必填query是现有明确契约，不变为body/query双收。本期对缺失、非法和重复version给出具体query提示，OpenAPI参数说明与README同步。
- M-2：归档状态不可恢复、role_id非空外键、引用包含归档账号均为已确认契约。当前实现允许超管维护归档资料或迁移其角色，因此“没有任何接口能释放旧角色引用”的报告不成立。用户裁决保留规则，只改善提示与文档；不能只在计数中忽略归档账号，也不自动解绑、删除qa_tester或改写历史数据。有关联的旧角色可停用，停用仍保留引用；也可用现有PATCH /admins/:id将归档账号迁至另一有效角色，再删除无引用的旧角色。迁移不恢复归档状态。

## 实现与验证契约

CMS_NAVIGATION_PATHS、CMS_NAVIGATION_ICONS以逗号分隔，在应用配置层解析、校验、拒绝重复，默认均为空。path为最长255字符的规范内部绝对路径，无外部来源、查询、fragment、反斜杠或控制字符；icon为最长64字符的符号名。createRuntime从该配置装配access，不再独立写空数组；后续前端只注册实际存在的路径/图标。

合法page在目录为空时返回503 temporarily_unavailable并附path字段说明“尚无已注册页面”；配置了目录但path未知时返回400并说明未注册；page缺少path仍为400。图标可为null；非null未知图标400并给出icon说明。目录撤除后已有未注册page不出现在myNavigation，管理树保留原记录以便修正；不修改数据库行。

DELETE缺失/重复/非法version仍返回400 invalid_input，fieldErrors.version明确要求单一正整数query参数?version=N，JSON body不被读取。业务版本校验及404/409行为不变，未认证请求仍先401。角色删除409 resource_in_use明确包含归档引用，并建议停用或显式迁移账号角色；恢复已归档状态仍400 invalid_input并说明不可恢复，现有合法资料/角色维护保持。

本轮影响应用配置、导航业务校验与投影、HTTP错误/OpenAPI、测试装置与文档；无数据库迁移、DTO字段变化、异步任务或前端代码。先增加实际配置→runtime→HTTP/PG的失败回归，再修复；验证可配置page/action、默认未配置、非法目标、目录撤除、DELETE query及归档保护。最终运行四门、Bun/Node旅程和独立审查，不降覆盖率或弱化原断言。


## 扩展迁移复查补充

原复查会话确认4f9da0e的七项症状关闭，同时独立复现最小权限校验的兼容扩展缺口：owner只新增一张runtime无权表，旧实例ready从200变503。本轮保留已知必需表的存在性与精确权限，允许未知关系在表、列及GRANT权限全空时作为兼容扩展；未知对象获得任何有效权限仍拒绝，owner/member/CREATE/definer/审计guard检查不变。

采用每版本独立运行账号：先扩展迁移，旧账号不授予新增对象；用新产物给新账号授予其明确表清单，滚动期间不修改旧账号权限。回滚旧产物同时恢复旧运行账号，保留已扩展结构；不能用扩大旧账号授权或放开全部新表来换取就绪。旧账号仅在旧实例/请求/任务全部排空且回滚窗口结束后退役。新增危险definer/PUBLIC权限仍不属于兼容扩展。新公开ready回归覆盖新增table/view、未知授权拒绝与撤销恢复、必需表缺失及旧账号回滚。
