# Collections 操作开关与历史

状态：当前实施契约，2026-10-27。

集合 disableBulkEdit 禁止批量更新和批量从回收站恢复；disableBulkDelete 禁止批量归档；disableDuplicate 禁止所有复制入口，包括单条复制、批处理和排队任务。三个顶层布尔值默认 false，权限不能覆盖禁用配置。单条编辑、单条归档及单条恢复继续按原权限处理。层级多项移动属于批量编辑，单项移动保留；文档排序按独立排序能力处理。

配置在接受任务、幂等重放和每项后台执行时按当前集合重新复核。禁用后不会继续执行旧队列中的对应写入；失败项记录 forbidden，其他独立动作不被错误关闭。编辑器动作、集合元数据和批量操作控件反映同一配置，不能仅靠隐藏按钮实施限制。

history.maxVersions=0 表示全部保留，不按数量和 retentionMs 清理历史修订或其资产绑定。false 继续表示不开放历史产品入口，正整数沿用数量、时间及当前/发布/任务保护规则。历史详情的 updatedBy 按被选修订的真实 actorId 安全投影；当前文档的作者列不被历史读取修改，复制和恢复仍记录实际执行主体。

本次开关和零保留上限只影响行为配置，无新增数据库结构。部署重启前结束旧实例写入，使 API 和 worker 使用同一配置；恢复开关不重放已失败项，按现有任务与修订核对重新提交。回滚先停写并恢复相匹配的配置与应用。观测 forbidden 批处理拒绝、后台失败项及版本保留数量，验证覆盖直接 API、队列配置变更、幂等重放、真实 UI 和历史作者准确性。
