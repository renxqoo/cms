# 查询预设自定义字段

内建和自定义规则均消费当前候选预览返回的 filterConstraints 选项；下拉按返回值展示，不保留可绕开过滤的共享快捷开关。后台以实际 FieldRenderer 编辑 read、update、delete 三类自定义访问约束，沿用字段标签、布局、类型、只读和隐藏控制、条件与组件插槽。普通关系选择复用文档引用服务，具有 filterOptions 的关系以同一完整预设候选调用专属选项端点；内容语言、预设 ID、版本和初始快照令牌均保持关联。

预览请求携带当前名称、查询和完整三条访问规则。默认值仅在响应仍属于当前候选且数据或初始快照令牌确有变化时回填；令牌随规则提交且不反复生成。首次加载、重试和候选变化时，保留同一约束现有字段 DOM 与无效草稿，界面暂时只读；身份、语言、源版本和约束切换时隔离旧结果。每次请求绑定 AbortController，关闭、卸载和候选变化取消旧请求，迟到结果不再覆盖输入。

保存按钮按完整候选的预览结果和本地字段有效性共同门控；预览未完成、失败或本地无效均禁止提交。选择内建规则时使用现有严格访问规则契约。修改、共享和删除同时消费当前角色操作权限及行级 permissions，不以 owner 身份绕过行策略。禁用查询预设时入口和请求均关闭。

本次 UI 不新增持久化结构，消费同一次发布的预览、字段选项和 metadata 契约。后端接口与前端同时切换；回滚一起恢复，不保留整对象 JSON 编辑器或重复字段渲染实现。观测沿用请求错误和现有操作审计。

指定用户复用现有 Select 和 admins.list。具备目录权限时按姓名或邮箱搜索并持久化身份 ID；无权限不读取目录，保留已有 ID 并说明输入已知 ID 的方式。搜索关闭、权限变化和主体切换均取消旧请求，结果不跨主体复用。
