# Collections 页面信息与图像

集合描述、页面标题、描述和标题后缀支持语言映射，精确语言优先，其次基础语言，再回退集合默认语言。`collections.get` 可显式选择 locale。配置仅接受已支持的声明式 Next Metadata 顶层字段和 JSON 值，不传递函数、模块或运行时对象；URL 字段只允许站内相对路径或 HTTP(S)，metadataBase 使用绝对 HTTP(S) 地址。内部链接另按文档引用持久化，不使用页面 metadata URL 冒充公开内容地址。

默认集合、文档、新建页面和注册 view 的实际服务端入口消费 metadata；viewport、主题色和颜色方案通过 Next 的 viewport 入口呈现。服务端先验证当前身份、集合可见性与文档读取权限，缓存仅在当前 React 请求内共享，不跨主体缓存。

OG 图片路由每次重新授权。dynamic 使用授权文档标题，static 使用统一品牌图，off 返回不可用；显式配置的 Open Graph 图片优先。响应始终 private、no-store 并按 Cookie 区分。图生成使用原生 worker，只接收授权后的文字与本地资源路径；worker 禁止网络，不继承请求凭据。尺寸、文本、字节、并发、内存和超时预算由所属 app policy 与现有请求配置控制，取消信号贯穿会话、集合及文档读取和图像生成；客户端取消或请求期限到达会中断尚未结束的上游读取，终止 worker 并释放名额。

字体来自固定版本的 Google Noto Sans SC，保留 OFL 和来源、原始与派生文件哈希。400 字重静态派生避免当前图像解析器的可变字体限制；本地字形范围以外字符使用缺字标记，网页 metadata 与文档原文保持完整。构建生成私有 worker 产物并追踪字体和渲染依赖；开发和生产使用同一套实现。

该变更不迁移内容存储。部署同时切换后端契约、管理端代码、构建的 worker 和字体；回滚同样一起恢复。写入内部引用链接后，不直接回退到不识别该 AST 属性的后端；保留可读取这些快照的版本，或在受控离线迁移验证关系与历史完整性后切换。

验证分别覆盖真实 library PostgreSQL 的内部链接历史、复制、发布、删除约束和语言 metadata；真实 worker PNG、拒绝、取消与资源释放；独立的 Next 开发和生产请求验证页面 Head、私有图片和打包路径。使用传输替身的 Next 旅程明确标记，不作为数据库权限验证的替代。
