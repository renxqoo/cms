# 内容集合侧栏菜单

状态：已核销。级别：中。

## 契约与裁决

用户裁决：内容集合成为独立的可折叠菜单，每个可访问集合是子菜单，点击直接进入既有文档列表。只调整展现形式，单例集合也保持列表入口。原 `/dashboard/collections` 总览作为辅助入口，保留空目录、权限说明、刷新与配置入口。

菜单名称、顺序和集合来源使用 `collections.list` 的真实结果，继续检查当前集合读取许可。仅当现有导航装配包含可用的集合总览入口时生成独立菜单；已配置导航隐藏该入口时不追加菜单，不改变无配置菜单时的现有操作许可回退规则。已存在的同目标链接去重。集合读取失败和读取中不表示为空集合；通过明确状态及总览入口提供恢复路径。

外部 HTTP、DTO、持久化、运行配置和后台任务契约不变。菜单链接使用既有 AppLink，继续执行未保存内容离开保护。列表、搜索、编辑、发布、资源上传和实际授权由各自现有功能负责。

## 影响面与拆分

`features/collections` 拥有集合菜单投影、读取状态和集合面包屑；`features/session/admin-shell.tsx` 负责装配。共享 shell 仅增加分组反馈插槽，继续复用既有分组按钮、滚动、键盘焦点、移动端关闭及折叠侧栏的可访问名称，不创建第二套侧栏。不新增包公共导出或后端依赖。既有查询工具增加仅供本地资源隔离的 `contextKey`，不发送到 HTTP；菜单以角色、操作许可和导航快照作为上下文，变化后立即隐藏旧结果并取消旧请求。查询停用期间的临时上下文变化不能清除原 403 抑制，避免权限刷新循环。

集合列表、新建、编辑、结构页面均高亮所属集合。面包屑提供总览、集合列表及当前操作层级。其余页面及 `/ui` 的视觉与交互保持现状。

## 并发与一致性

每个管理 shell 至多有一个菜单集合查询，无轮询和新增定时器。复用现有请求取消、超时及认证失败处理；离开 shell 或许可变化时取消请求。菜单仅消费当前许可允许且成功返回的集合；加载或失败不显示过期子菜单。总览仍拥有自身刷新行为，不建立跨用户缓存。

## 实施与回滚

先增加行为测试并确认新目标在旧实现失败，再实现纯菜单投影和 shell 装配，最后增加真实开发/生产浏览器旅程。无需数据迁移或兼容窗口；提交内一次切换为独立菜单。观察集合请求错误、导航可见性及列表/编辑高亮。回滚本次提交即可恢复原导航展示，既有 URL 和数据无需恢复。

## 测试口径

- 有入口时生成独立菜单，集合顺序及名称来自接口，点击抵达现有列表；无入口、无许可、加载失败及空目录分别验证。
- 保留其他导航及自定义名称，消除重复集合链接；显式配置其他菜单时不能凭操作许可追加集合菜单。
- 完整应用菜单场景逐项核对用户、角色、权限、导航、接口、访问恢复、审计、资源、任务和资源清理入口，以及概览和账户设置，集合提升分组后均保留。
- 路由按段匹配，集合列表、新建、结构、编辑及相近集合名高亮正确；面包屑返回正确集合与总览。
- 许可刷新、迟到结果、查询取消不留下旧菜单；侧栏收起仍有可访问名称，移动端选择关闭抽屉。
- 使用现有内容浏览器装置验证菜单直达、折叠、编辑高亮、未保存离开保护及窄屏操作，不修改真实业务数据。
- 会话撤销旅程先等待初始操作许可、导航和集合菜单查询完成，再从外部撤销令牌并验证深链接过期处理；避免撤销步骤与仍在运行的初始菜单查询竞争，继续保留全部身份与错误断言。
- 执行相关测试、lint/typecheck/build/test 四门与独立对抗审查，报告实际用例数及 S/B/F/L 覆盖率，不调整阈值。
