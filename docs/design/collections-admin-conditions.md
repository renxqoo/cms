# Collections 条件呈现与组件注册

状态：已实现，统一集成验证由根工作区执行。参考本地 Payload 字段 condition 与受信任组件配置能力，使用统一编辑器与独立身份权限。

## 候选上下文与实时条件

collections.previewEditor 使用 POST /v1/collections/:collection/editor/preview。输入为有界完整表单候选，包含当前语言、编辑意图以及已有文档的 id/revision。与选项查询共用 withEditorCandidate 的事务内授权与快照：建立实际读写权限、核对 CAS、按现有规范化器归并字段值，并只拒绝越权改变，保留未改变的只读字段。隐藏字段不能被客户端新增、重写或通过条件布尔值探测。

条件为受信任、版本化函数，接收可读候选 root/sibling/block、稳定行路径、用户与实际编辑操作。函数不发送到浏览器；使用与 hooks 相同的调用总量、期限和取消预算，异常以安全错误码反馈。结果只控制显示，最终存储授权、类型和校验继续在真实写入执行。条件隐藏的值继续保存在本表单状态，重新显示恢复原值；过时预览响应不能覆盖更新候选。

新建编辑器返回 initialData 和 initialSnapshot。快照只包含已投影的初始可读值，以现有共享服务端密钥作独立用途的 HMAC 签名，绑定用户及委托凭据、集合、语言、behaviorHash 和会话期限。create 候选带回该快照作为差异基线，未变只读默认值不进入写入 patch；动态默认函数不在预览中重跑。直接 API 候选可省略快照并以空值为基线，授权不放宽。篡改拒绝为 invalid_input，过期或身份、集合、语言、配置不匹配拒绝为 version_conflict；真实保存仍执行既有服务端默认值与最终字段写权限。

## 组件注册

字段与集合配置只引用随应用构建的组件标识。服务端验证注册标识与合法插槽，管理端从显式注册表装配 React 组件，未知标识失败，不执行动态源代码、远端 import 或浏览器内配置函数。自定义字段沿用标准标签、错误、只读、值更新与当前候选上下文；自定义单元格、标题、集合视图不得绕过后端返回的权限投影。

字段支持 Field、Label、Description、Error、Cell、beforeInput、afterInput；集合支持 Header、List、Edit 及 beforeList、afterList、beforeEdit、afterEdit。服务端 metadata 只返回实际可读布局的引用与 componentVersions，编辑器加载时核对本地已构建注册表的插槽与版本。缺失或版本不匹配阻止新表单写入；组件运行异常提供中英错误与重试，并保留标准控件和值。隐藏控件保持挂载与 inert，未能解析的本地输入不会因隐藏而消失；有无效输入时统一错误阻止保存。

## 迁移与回滚
