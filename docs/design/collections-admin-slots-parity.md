# Collections 管理端定制

管理端定制通过受信任的注册组件 id 装配。引用可禁用默认呈现，也可指定已注册 id 与 JSON props；不加载配置中的任意模块路径，不把服务端函数传到浏览器。组件版本、适用插槽和 props 校验均由受信任注册定义，服务端 props resolver 使用请求权限投影后的数据、共享函数预算和取消信号，结果只允许经过校验的 JSON。

字段定制覆盖控件、标签、描述、错误、单元格、过滤器、历史差异、数组行标题、block 容器和标签，以及输入前后内容。UI 字段只参与管理端布局，不进入物理 schema、修订、默认值、业务验证或输入数据；条件显示仍使用授权候选。数组和 block 的定制上下文保留稳定行 id。

集合定制覆盖列表整体、表格前后、空结果、列表动作和菜单；编辑整体、文档控件前、元数据前、状态、保存、保存草稿、发布、撤回、预览、上传和编辑菜单。集合与文档的注册自定义 view 使用明确路径、导航 tab、动作和页面 metadata；树形导航和文件夹图标使用相同注册边界。每个配置项必须有实际入口与消费位置。

编辑器、复制的每种语言和批量编辑均重新计算候选条件与组件 props。批量条件取同一事务内各源文档的交集，不用某一条的可见性代表全选；隐藏控件保留未提交输入，取消、过期响应、错误与重试沿用既有控制器清理契约。

此增量直接切换现有组件注册单轨，不保留旧执行器。观测组件版本不匹配、props 校验失败、resolver 超时、取消和越权拒绝；回滚同时恢复配置、后端 DTO 与管理端版本。组件呈现不修改存储格式或身份架构。

验证使用公开业务 API、真实管理端组件与浏览器旅程，覆盖插槽实际替换、false 禁用、props 数据通道与权限、UI 字段无持久化、复制和批量条件、嵌套行上下文及取消清理。完整四项门禁在合并后串行执行。

字段可以分别禁用编辑区、列选择、过滤器或批量编辑；UI 字段默认不参加批量编辑。UI 容器可只使用输入前后内容，无需提供 Field 控件，注册 Cell 和 Filter 仍能使用授权数据。集合及字段标签按精确语言、基础语言和配置回退解析。集合图标与层级图标分别消费各自配置。

同一组件可在插槽数组中重复出现，服务端 props 使用插槽位置区分实例。自定义控件可以报告局部无效输入，数据仅在控件提交合法值时改变；隐藏、切换只读或卸载时释放该实例的校验状态。组件版本、DTO 和管理端同时发布，旧版 props key 不设双轨兼容；回滚须同时恢复三者。

富文本链接可以保存 URL，也可以保存集合与文档 id 组成的内部引用，两者互斥；内部引用与文字子树一起无损持久化，并进入既有关系读取权限、发布检查和删除约束。内部链接与关系节点各自按目标集合的资格过滤，现有已保存内容不因资格开关变化而删除。内部候选沿 Admin 查询上下文执行基础过滤；外部 URL 链接继续使用既有协议校验。
