# 字段复制和后台展示配置

`FieldDefinition.disableDuplicate` 为 true 时，文档复制先删除源文档中该字段的值，再合并调用方明确提供的副本数据，并运行普通新建的默认值与验证。分组、命名标签页、数组和块递归应用同一规则。文档本身、历史恢复和复制语言不受此开关影响；批量及异步复制消费同一后端复制准备函数。所有副本数组和块都获得新行 ID；跨语言共享容器的同一行使用相同的新 ID，本地化容器分别生成。复制的媒体引用将新行路径映射回源修订固定快照；替换源文件、删除源历史及存储清理后，副本仍下载原字节。调用方明确改选的引用按普通新引用授权，缺失的原快照不会回退到当前文件。

字段 `admin.readOnly` 只控制后台交互，不改变 API 字段写权限。UI 只读父字段的子字段可显式设置 false 恢复编辑；字段访问策略拒绝、整个页面只读、忙碌和租约阻塞仍强制只读。`admin.hidden` 隐藏后台控件，保持文档数据和 API 读写权限；隐藏不能替代访问控制。既有条件和 disabled 分区仍各自生效。

`admin.description` 和 `admin.placeholder` 支持文本及语言映射，按编辑语言解析，描述作为默认 Description 插槽内容，注册组件仍可替换。占位文本用于实际输入和选择控件。`admin.position` 支持 main 与 sidebar；主编辑区和侧栏在宽屏并排，窄屏按阅读顺序堆叠。嵌套字段保持在其所属容器。`admin.width` 支持有限数字像素或有长度限制的 CSS 宽度字符串，使用字段组件内的动态 CSS 变量消费，窄屏仍占满行。

所有展示配置经过严格配置 schema 和安全编辑器 DTO 输出；不可读字段不会因展示配置出现。行为配置不进入物理字段指纹，不需要 SQL 迁移。配置变更随 behaviorHash 切换，旧编辑上下文按现有刷新规则更新。回滚移除配置及消费者，不维护旧路径别名或重复配置；复制后已生成的数据仍是普通文档。观测使用当前编辑器契约、实际复制修订和已有请求审计。

字段草稿在输入事件内同步保留当前校验结果；初始化上报不会覆盖先发生的无效输入。界面错误仍由组件状态呈现，替换或卸载草稿仅清理该字段身份的错误，其他语言和字段实例保持各自校验状态。
