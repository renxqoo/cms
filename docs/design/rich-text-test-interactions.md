# 富文本工具栏交互验证

富文本编辑器使用 Next.js 客户端动态组件与 Lexical 0.52.0。工具栏的块类型来自编辑器当前 RangeSelection；段落内容已经恢复，不代表编辑器仍有选区。工具栏按钮的 mousedown 会阻止默认焦点转移，列表切换测试使用 await userEvent.click 执行完整指针交互，保留这一真实行为。

列表切换回归保留原有内容、DOM、按钮状态断言和默认 waitFor 期限。三个阶段分别标记列表插入选中、列表移除取消选中、段落恢复选中，失败时可明确定位，避免把不同阶段的 aria-pressed 差异误认为同一初始化问题。测试不增加等待、重试或放宽断言，生产组件与 Lexical 插件注册不变。

验证记录：原单 click 事件测试在 100 次重复中复现最终段落按钮未选中；诊断同时确认数据与 DOM 已恢复为 Story 段落，但 activeElement 为 BODY，DOM 选区为空，三个块按钮均未选中。实际列表插入和移除已经完成，因此该反例不支持命令尚未注册的解释。仅替换两次列表点击后，四个用例各重复 200 次，共 800 次执行通过。该局部结果不代表全仓 CI 通过，完整门禁仍按仓库脚本执行。
