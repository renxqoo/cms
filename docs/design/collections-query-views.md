# 分组与查询视图

分组沿用普通列表的集合、内容语言、回退、编辑/发布、归档、文件夹、搜索、筛选与文档排序规则。documents.distinct 返回字段的不同值页；documents.groups 返回不同值页及每组的文档页。分组值顺序与文档顺序分别指定，每组的页码与页大小可以独立改变。数组、多选、重复结构及关系路径按各可见值分组，同一文档可出现在多个组；空值及缺省值归入空值组。分组、去重、计数和分页在 PostgreSQL 中完成。

分组读取同时要求对应操作及 documents.list，交集策略在 SQL 分组和计数前执行。字段及遍历关系路径继续使用当前语言的查询权限与目标行策略；被拒绝的目标值不参与分组。链接到关系路径的虚拟字段可以沿已授权路径分组，动态计算字段不能用于数据库分组。管理端只列出允许分组的字段，并消费返回页；禁止先拉取文档再在浏览器分组。

documents.groups 的 page/pageSize 控制不同值页，groupPageSize 控制组内默认大小，queryByGroup 按稳定不透明键指定组内 page/pageSize；sort 控制每组文档顺序。键由集合、字段与规范值确定，不编码位置或隐藏记录。不同值为 null、JSON 标量或规范关系引用；日期统一使用现有 UTC 表示。所有页大小、组数、查询节点、返回字节和展开节点服从注入的资源策略。预设保存 groupBy，页码是当前列表导航状态。

分组是新增读取接口，不改变现有列表响应。切换管理端、业务和客户端产物时使用同一版本，不增加旧数组结构或参数别名。观察分组权限拒绝、查询节点、展开节点、响应字节、独立页总数及请求取消；异常时回滚本轮代码及同版客户端，既有预设未包含 groupBy 时继续正常加载。groupBy 为 JSON 查询状态的可选字段，已有预设不要求重写正文或重置版本；回滚前移除新增分组状态即可恢复旧管理端。
