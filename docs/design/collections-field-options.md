# Collections 关系字段选项

关系与上传字段配置 filterOptions 时，安全编辑元数据只投影 constraints.filterOptions 标志。管理端通过 collections.fieldOptions 读取候选选项，不接收配置函数。请求包含完整当前表单、集合、语言、编辑模式及真实编辑身份；创建携带编辑描述的 initialSnapshot，更新携带当前文档 ID 和 revision。服务器重新验证候选、字段策略及目标集合读取权限，配置筛选与既有查询约束相交。

字段路径采用稳定的数据身份。普通字段使用字段名，数组与区块行使用持久 UUID，不使用可变行下标；目标集合通过 relationTo 指定。搜索、页码及当前语言与候选一起发送。普通关系字段及未配置动态筛选的批量编辑继续读取 documents.list，保持原有语言、分页与权限约束。

配置动态筛选的批量更新通过同一 candidate 参数传入有界数组。每个候选包含各自文档 ID、revision 和当前共享补丁，不重新预读其他正文。服务器在同一安全事务逐源恢复并验证候选，对全部目标条件取交集后执行一次分页查询，rows 与 total 来自同一交集；预算不足明确失败。不存在单独的批量筛选接口或宽松回退。

管理端引用服务绑定页面实例内的当前编辑快照与完整表单。字段、同级字段、语言或编辑身份变化都会使旧查询失效，取消尚未完成的请求，并忽略迟到结果；查询身份变化直接使用第一页，不以副作用同步分页状态。关闭选项面板或卸载页面会取消请求。缺少候选上下文、只读身份或语言不匹配时明确展示选项读取错误，不转为更宽的普通列表查询。选择值只保存真实集合与文档 ID，显示标签不进入数据。

复制对话框按语言分别绑定 copy 编辑描述、源文档修订和该语言的当前副本表单，不复用主编辑页的 update 候选。用户只具有复制权限时仍可按复制上下文获取候选选项；切换语言会关闭旧语言的选项面板并取消其请求，各语言已编辑的值继续保留。

切换采用统一 API 与管理端产物：先停止旧写入者，再启用新配置并恢复写入；无旧字段参数别名或双轨查询。观察字段选项 forbidden、version_conflict、invalid_input、取消率与查询预算错误，并验证正常选项、空结果、跨语言权限和旧请求迟到。回滚使用上一统一配置及应用产物，不修改关系持久数据；已启用配置不得只回滚管理端而保留不认识该约束的旧写入者。前端不以自身筛选结果替代写入时服务器的最终关系校验。
