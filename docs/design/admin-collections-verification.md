# 内容管理界面实施与验证

状态：内容界面及针对性验证完成，统一四门和远端 CI 由主工作树核销。范围遵循[内容实施契约](admin-content-implementation.md)，未部署、未变更数据库或后端业务协议。

## 当前界面

- `/dashboard/collections` 发现实际可读集合；集合列表提供服务端分页、搜索、可查询字段筛选、排序、可选列、明确选择及回收站。
- `/dashboard/collections/[collection]/new` 和文档详情使用安全 editor 元数据及现有二十类字段渲染器；单例入口先通过无筛选列表发现真实文档 ID。
- 结构页面只读展示实际安全布局、schema、语言和 schema 标识，不执行运行时建表。
- 文档操作包含手动保存、选择启用的自动保存、发布及撤回、复制、历史比较及完整历史恢复、归档、回收站恢复和永久清除。
- 文件夹使用真实树、collection 范围和版本 CAS；文档移动通过当前修订的 PATCH 完成。
- 批量修改最多十项，逐条读取并匹配 update 元数据；其他批量动作最多一百项。提交明确 ID/revision，展示真实逐项结果或持久化任务入口。
- 发布计划提交明确版本、当前修订及 UTC 时间，受理后提供实际可重新发现的任务入口。

上传、替换、图片处理和固定历史媒体通过同一编辑器装配资源模块；业务页面使用统一客户端和封闭 BFF，页面服务端验证身份，后端逐次再次授权。

## 编辑与生命周期约束

catalog、editor 和 document 核对集合、schemaVersion、behaviorHash、mappingFingerprint、修订及版本；交错读取最多重取一次。编辑数据始终由明确 locale、fallback=[]、depth=0 的读取取得。省略 locale 时让后端选择实际默认语言，文档读取消费元数据返回的 locale，不按 supported 数组顺序猜默认值。

写入按编辑器实例串行。发送后继续编辑、无效 JSON/富文本结构草稿和光标所在字段实例会保留；确认采用服务器快照时才重置字段树。CAS 冲突提供服务器最新数据与显式丢弃或保留草稿的选择。

自动保存使用独立 autosave intent 校验字段权限。只移动文件夹不会发送空自动保存；字段自动保存后仍保留待手动保存的文件夹目标，不显示全部保存成功。默认静默窗口十秒，定时器在关闭或卸载时取消。

复制逐语言读取 copy intent 元数据和无 fallback 文档，保持各语言字段实例，允许分别修改唯一值。提交仅使用 revision/dataByLocale；每个语言的补丁都必须在当前 copy 投影中完整可写，源文档保持不变。

未知结果只对实际声明幂等的操作保留同键同载荷重放；该核实不再次用已经推进的源修订阻断原幂等回执。非幂等 PATCH/DELETE 先读取当前数据，归档通过授权回收站列表核实；文件夹更新或删除读取真实树后显式采用当前 CAS。不会盲目改键重试或声称未知操作完成。

复制弹窗关闭后才提交副本导航；共享离站保护实时读取嵌套 scope 状态。布局不使用延迟、额外导航器或点击“离开”掩盖已完成操作的残留 dirty。所有异步读取、写入、监听和自动保存定时器都在卸载时取消。

## 实际验证

本工作树针对性类型检查通过，最终检查 714 个文件；类型感知 Oxlint 和自有文件 Oxfmt 检查零错误、零警告。

Collections 联合单元与公开组件测试八文件、一百一十一用例全部通过。作者核心测试与独立作者公开界面测试共同覆盖实际读写契约、字段投影、晚响应、未知结果、文件夹 CRUD/CAS、单例、批量、历史、计划、键盘关闭及焦点恢复。

诊断覆盖范围仅为 `apps/admin/src/features/collections/**/*.{ts,tsx}`：statements 91.35%（877/960）、branches 87.46%（907/1037）、functions 91.02%（294/323）、lines 95.13%（782/822）。原 90/85/90/90 门槛在此局部诊断中通过；不以该数字代称全仓覆盖率或远端 CI。
