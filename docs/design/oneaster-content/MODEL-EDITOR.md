# 模型编辑器

models 维护模型资料、公开接入说明和运营样例。Core 继续拥有真实模型执行、供应商线路、凭据、价格、账务及任务状态。

编辑器使用六个无命名标签页：基本信息、技术资料与参数、接入方式、详情内容、展示样例、推荐与 SEO。原字段 ID、字段路径、顺序、持久化类型和公开 DTO 保持一致；不增加嵌套数据层或模型系列集合。

字段标签、选项和说明支持中文与英文。业务模型 ID 与页面 slug 分别说明用途；技术资料不表示本站实时可用性。根据参数类型和样例媒体类型控制适用字段的可见性，隐藏不会清除已经保存的资料。

JSON 字段通过注册的模型字段组件编辑：发布语言使用集合语言候选；语言和来源支持列表使用字符串列表；来源信息使用结构化字段；请求示例从现有 profile/flow 的 Zod 请求合同生成字段，保留 JSON 编辑方式。嵌套表单复用现有字段渲染器，编辑数组使用的行 ID 不写入请求示例。

默认绑定与默认场景从当前候选记录选择，flow 候选按 profile 过滤。模板默认使用现有 core.http。由当前 profile/flow 唯一确定的调用模态与能力自动提供；最终发布继续执行真实请求合同、技术能力范围及默认引用校验。资料参数与实际调用示例分别维护。

本次没有物理存储切换或新旧字段兼容窗口。API 与管理端配套部署，组件版本及生成的行为摘要用于检查配置一致性。观察模型编辑错误、invalid_input、组件版本不匹配及发布失败；对应回归与四项检查通过后完成切换。回滚使用上一版配套 API 和管理端，已有资料仍使用相同字段和公开形状。
