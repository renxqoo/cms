# 预设参数与查询上下文

集合默认开启查询预设，enableQueryPresets 为 false 时拒绝预设操作并隐藏管理入口。预设按 read、update、delete 分别设置 everyone、onlyMe、specificUsers 或 queryPresetConstraints 注册的约束。集合操作权限与预设规则取交集，所有者不绕过规则。创建或修改共享规则时，onlyMe 使用当前写入者，specificUsers 自动包括当前写入者。普通名称和查询更新保留既有访问规则、参数及引用索引，不能转移删除权限。新增或修改后的 read、update 必须允许写入者，避免锁出。版本号通过同一事务的行锁和 CAS 验证。

自定义约束以明确版本的异步回调判断当前预设及参数。filterQueryPresetConstraints 复用既有字段选项过滤管线，读取管理元数据、预览候选和最终保存均应用过滤，遵守请求取消、函数次数及时间预算。参数声明使用现有字段布局、校验、读取与写入权限、条件、动态选项和字段渲染器。候选预览与参数关系选项复用现有编辑器管线，不创建内容文档身份。动态默认值签名仅含可读取数据，绑定主体、委托、集合、预设、动作、约束、当前语言及行为版本。

当前预设参数是全局结构，localized 字段、Join、virtual 及非 restrict 的关系删除策略在配置阶段拒绝。集合文档自身的多语言、Join 和 virtual 使用现有实现。预设内容语言用于权限和查询资格投影，预设查询本身不绑定语言。

关系、上传和富文本参数只引用经授权、可读取且未归档的内容文档。上传及富文本媒体必须指向上传集合的已存在文档，继续由该文档的固定媒体绑定管理文件。0024 的独立引用索引覆盖全部参数引用；被引用文档在参数解除或预设删除前不能归档或物理删除。改写和索引替换在同一内容变更事务内完成，源预设删除通过外键释放索引。

0024_query_preset_access.sql 将旧 shared 迁为 access JSONB 并删除旧列。shared 为真的预设迁为 everyone-read、onlyMe-update/delete，其余迁为三项 onlyMe，users 使用原所有者。HTTP 写入只接收 access，DTO 中 shared 是派生摘要，不接受布尔旧输入。切换窗口停止旧 writer、管理端和 CLI，备份后同时迁移数据库及同版本应用、SDK和管理端。核验私有/共享读取、三项授权、CAS、锁出、引用约束、取消和字段资格；观察拒绝率、版本冲突、函数预算、SQL预算及返回字节。未发生新版写入时可审核逆向迁移恢复旧 shared；存在具体用户、自定义约束或参数引用后，先导出并审核所有访问规则、停止写入，再按导出记录回滚，不直接扩大读取范围。

collections.list/get 的 locale 是内容语言偏好，每个集合对不支持的语言使用自身默认值。元数据及隐式默认排序只采用该语言允许查询与读取的路径；显式未授权排序仍失败。context: admin 仅在管理列表、分组、去重和内部文档候选启用 baseFilter 与额外 listSearchableFields。搜索域与原 search 合并，额外规则不改变普通文档 API；管理 URL 回调在授权、展开与全语言投影完成后执行。
