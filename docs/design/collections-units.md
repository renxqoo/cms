# Collections 单元契约与测试矩阵

状态：已核销，2026-10-26；测试口径先于实现。实际门禁数字见 [验收记录](collections-verification.md)。

## 1. 存量不变量

身份/RBAC 全量回归；默认无绑定拒绝、global 不兜底 collection、撤权先提交则写入失败、审计/幂等/业务原子、Node 可运行、取消释放连接、未知输入拒绝。所有新增操作注册与 HTTP/OpenAPI/目录一致，HEAD 继承 GET。

## 2. 新规格矩阵

| 单元 | 正向 | 边界/异常/并发 |
| --- | --- | --- |
| 配置与注册表 | 两集合、稳定身份、元数据、函数版本 | 未知配置、重复/保留名、关系错误、不适用模式、冻结、输入不变 |
| 生成与演进 | 确定性 SQL/Drizzle/类型/schema、无生成物可执行、重命名保留字段 | 计划漂移、缺迁移拒绝 ready、破坏性变化要求显式转换、历史旧 schema 恢复 |
| 字段 | 每类型保存/读/筛选/索引/恢复 | 空/零/false、未知键、精度/长度、超深/超大、默认值、草稿缺必填/发布拒绝 |
| 组合/locale | 多级数组、blocks、group/tabs、稳定 UUID/顺序、显式回退 | 重复子项、非法 block、跨语言污染、缺值/null/空字符串、locale 唯一 |
| 富文本 | versioned 树、引用提取、安全输出 | HTML/脚本/危险协议、未知节点/版本、节点/深度/字节超限 |
| 关系/join | 单/多/多态、反向读取、有界展开 | 目标类型/不存在、跨集合越权、循环/预算、归档目标、删除/引用竞争 |
| 查询 | 类型化 AST、and/or、路径/q/sort/page/select/depth | 未知路径/操作符、注入、隐藏字段过滤/排序/搜索、总数侧信道、published 选择准确 |
| 唯一与索引 | 单/复合/locale/current 唯一 | 历史重复不阻挡、并发当前冲突、回收站占用、单例并发 |
| 文档 | 创建/保存/复制/发布/取消发布 | 幂等重放/不同输入、revision 竞争、发布缺字段、回滚及撤权 |
| 版本 | 历史列表/详情/diff/新修订恢复 | 别文档 versionId、字段授权、模式不适用、schema 不兼容、直接生效写权 |
| 回收站与保留 | 归档/重复归档/恢复/purge/裁剪 | 保留时间、外部历史引用、自身引用释放、活跃/发布/计划保护 |
| 任务 | 批量真实逐项结果、计划确定修订、持久化可查询 | 跨实例领取、进程重启、过期代次 CAS、撤权、取消竞争、部分失败/失败统计授权 |
| 扩展 | 版本化转换/校验、提交后持久化意图 | 规则失败回滚、不能跳过授权/审计、不在事务内等待网络、重试/取消 |

## 3. 安全与接缝

主体（owner/editor/reader/无权/撤权/未认证）× 集合（articles/pages）× 操作，验证列表 rows/total、详情、版本、diff、关系、任务和写路径；super 也受引用/版本完整性限制。故障注入审计、子写、提交及任务抢占，真实 PG 验证最终状态。

Bun 和 Node 同一旅程：初始化 → 建角色/collection 权限绑定 → 编辑者草稿 → 无发布权拒绝 → 授权发布 → 修改草稿不改变 published 排序/总数/值 → 恢复/归档 → 撤权拒绝及幂等重放拒绝 → 服务重启任务仍可见。

## 4. 门禁与审查

不改变 vitest 匹配范围/阈值（整体 statements/functions/lines 90%、branches 85%）；新增真实业务代码纳入既有通配。每个修复记录缺陷前失败和修复后通过证据。最终独立检查无新增 skip、弱化断言或虚构成功。报告整体实际覆盖率，不能把局部覆盖率说成全仓。
