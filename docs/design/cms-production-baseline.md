# CMS 生产交付基线

状态：定稿，2026-10-27。用户裁决：按现有架构补齐内容与资源 CMS，先完成代码和可复现的部署验收方案。租户管理由业务系统负责；后续业务将管理 AI 模型列表与详情、Skill、提示词，要求多语言及 SEO 友好。沿用 TypeScript 内容模型与既有技术栈，不把本机验证等同于生产部署验收。通过全部代码门禁后合并到 `main` 并推送；生产部署需另行授权。

## 1. 交付范围

当前能力由真实代码及公开接口验证：身份与账户恢复、管理员及 RBAC、导航与操作绑定、审计、配置驱动集合及二十类字段、多语言、关系、文件夹、草稿与发布、版本与恢复、回收站、批量与计划任务、上传型集合、私有文件、图片处理及清理恢复。既有业务契约继续以各专项设计为准。

生产交付同时包含可理解的编辑界面、错误恢复、权限一致性、资源释放、四项工程检查、真实开发及生产进程旅程，以及部署、备份恢复、容量和故障演练的明确验收记录。不能以功能入口存在或单元测试通过代替业务终态。

本批聚焦内容与资源，已有账户/RBAC、导航及审计作为依赖全量回归，不增加租户管理、SSO、审批流或运行时可视化建模。后续 AI 业务内容通过实际集合配置接入，当前不创建未消费的 AI 模块。CMS 支持本地化文本、可查询唯一 slug 和媒体引用；SEO 标题、描述等属于内容字段，业务站点负责页面路由、canonical、hreflang、sitemap、robots 与结构化数据输出。公开交付身份及缓存必须在真实消费接口接入时明确，不把管理 API 隐含开放。

## 2. 本批行为契约

列表选择属于明确的查询范围；跨页及排序保留选择，改变回收站、语言、发布视图、搜索、字段筛选或文件夹时清空。浏览器前进后退也必须遵守，不能依赖仅在按钮事件里清理。范围变化后的旧选择不得再次出现。范围切换关闭未提交的批量弹窗；离开正在提交或结果未知的弹窗沿用现有离站确认，用户确认离开后中止本地请求，不声称远端任务取消；已受理任务通过任务目录重新发现，不自动改键或载荷再提交。批量请求始终使用打开时的明确 ID/revision/locale，不自动重读修订后替用户确认。

编辑视图及编辑器对草稿集合区分草稿、已发布和已发布但有未发布修改；直接生效集合显示已生效，回收站优先显示回收站。published 查询只返回发布版本，列表显示“线上快照”，不据此判断当前编辑版本是否已发布，也不为状态标签额外取得未授权编辑数据。列表及编辑器复用同一状态规则。

集合级更新许可不能代替逐文档更新资格。更新 editor 被资源规则拒绝时，允许重新取得明确的 read editor；仅当 read 成功且服务端动作表明确拒绝 update 时展示只读内容。身份失效、网络失败、服务器错误和快照不一致不降级为假成功。只读模式不渲染更新入口，不扩大后端权限。

集合目录 DTO 增加必填 `defaultLocale`，由服务端实际集合配置投影；列表省略或传入不支持的语言时使用该值，不按 supported 数组顺序猜测。同步更新 OpenAPI、浏览器契约及调用装置。无持久化变更；先部署增加字段的 API，再部署消费该字段的前端，滚动窗口内旧前端忽略新增字段。回滚先前端后 API，不保留双字段或旧解析分支。

集合目录以业务文案描述草稿发布、直接生效、单例和媒体能力。技术标识进入可展开详情。结构视图展示安全字段、类型、必填和本地化规则；技术 schema 保留为可展开详情。普通无上传能力且无固定媒体绑定的文档不展示空文件卡片。集合/字段标签来自安全元数据，不能在浏览器以本地业务配置补回隐藏字段。

结构视图中，未单独声明本地化的嵌套字段展示“遵循父级语言规则”，并展示安全字段路径以保留父子语境；不能把字段自身 localized=false 推断为跨语言共用。顶层非本地化字段可显示所有语言共用，显式本地化字段显示按语言编辑。

## 3. 影响面与不变量

本批影响前端集合入口、列表选择、状态呈现、编辑读取、结构展示、媒体装配及其测试和文档。HTTP/DTO、持久化、后台任务与公共包导出按实际缺口决定是否变更，不预建接口。生产部署参数仍沿用已定义的配置，不引入新框架。

保留封闭 BFF、HttpOnly 会话、Origin 检查、后端当前授权、安全字段投影、无 fallback 的编辑数据、CAS、幂等及未知结果核实、不可变版本及媒体、任务重启发现和有限预算。所有请求、定时器与监听继续在实例卸载时释放。

本批前端行为随同一产物切换，无存量数据转换、双写或旧路径兼容窗口。观测指标为读取失败、403/404、409、批量逐项错误及发布状态一致性；回滚为恢复上一版前端产物，不修改已保存数据或服务端授权。

## 4. 生产验收边界

本机可复现验收与目标环境验收分别记录。目标域名、入口 TLS、SMTP、共享存储、数据库运行角色、备份策略、容量目标及故障域由真实部署确定。未选择提供方或未执行真实演练时，该项保持未验收，不声明 99.9% 可用性、RPO 0 或任何未经测量的容量。
