状态：已核销，2026-10-26；关联[设计](admin-ui-design.md)与[组件映射](admin-ui-components.md)。

## 1. 实施顺序与所有权

先审查三件套，处理问题后定稿。用户已授权实施和多个子agent并行；开发采用独立 git worktree，不共享写工作区。主会话拥有根 manifest/lock、工具配置、架构检查、CI、设计文档与最终集成；基础组件agent拥有 packages/ui；应用agent拥有 apps/admin 的 Next入口、shell、i18n和工作台；CMS组合agent拥有 apps/admin/src/components/cms 及其私有测试。agent仅交回点名文件补丁，不自行修改共享产物或push。

首批为正式最小切片：主题token、Button/Input/Field/Dialog、DataTable/FormDialog/SearchBar、后台shell与列表场景、语言主题、React测试和浏览器装置。首批先走四门及独立审查，校准契约与测试设施后在原代码上补齐其余39类指南，不能推倒另建临时实现。

全量阶段按组件映射补齐导航/选择/反馈/布局/拖拽/代码编辑、CMS关联/文档/上传及验收页。完整组件范围不因批次分拆而减少。示例数据只位于 ui-lab 与测试。每次跨工作区集成先同步真实公开接口；不得用强制断言、兼容别名或空回调消除接口冲突。

## 2. 开发前测试口径

基础原语：可访问名称、label关联、键盘focus、disabled/readOnly、显示错误；弹窗Esc/焦点恢复/嵌套/菜单触发。异步提交：同一提交只一次、成功关闭、业务失败及throw显示、关闭abort、旧结果不影响新会话。

列表：搜索/过滤/排序重置页码与其余参数保留、分页首尾、空/错误/重试/加载、稳定ID选择及半选、跨页策略、长文本横向访问；搜索覆盖IME组合与取消计时器。UI测试只通过公开组件和DOM行为，不绑定私有状态/函数顺序。

CMS：关系单多选/搜索/清空/只读/创建编辑入口及排序；文档动作权限×状态、批量部分失败；锁定/接管/未保存离开/冲突；文件类型与数量/大小边界、拖放/粘贴、预览URL回收、进度/取消/重试/替换/移除；裁剪焦点边界/键盘；拖拽结束与取消；代码编辑/只读/主题。

偏好与隔离：两种语言下文案和可访问名称完整；两种主题及重载保持；两个Provider/页面实例状态不串；无hydration/console错误；语言/主题切换不丢表单和选择。日期五种模式、min/max/清空null及IANA timezone值不因浏览器时区意外漂移。导航分组以稳定ID保持偏好，面包屑路由切换后无残留。多值文本增删排序、Pill/Select多选排序、creatable与分组选项、共享loading并发和路由过渡取消均以公开交互验证。离开保护覆盖Link、适配程序化导航、back/forward与beforeunload：取消保留输入，确认仅重放一次目标。

## 3. 装置适配

根Vitest保留现有Node/数据库用例；React用例使用单独明确jsdom项目或配置，包含tsx、Testing Library和清理。覆盖率保留现有范围并加入ui与admin实际TS/TSX源码，不因入口文件或UI难测而静默排除。

现有e2e/vitest.config.ts属于后端跨进程旅程；浏览器使用Playwright独立配置，通过同一 test:e2e 入口按路径分发，不让现有Vitest误收浏览器spec。test默认同时运行原后端旅程及开发/生产浏览器冒烟；浏览器启动动态分配端口，不占Tillgate的3002，不读取其认证或私有数据。生产冒烟使用真实Node执行Next产物，检查真实页面交互而非仅200。测试入口分配两个端口后通过CMS_ADMIN_E2E_PORTS仅向Playwright进程树传递，config/worker重复加载使用相同端口，避免每次加载重新分配；此变量不属于部署配置。开发和生产进程显式使用各自NODE_ENV。

本期组件映射不含图表，不保留无消费者的Recharts依赖；业务阶段需要图表时按仓库图表约定提供。依赖只新增本期实际使用包，查询稳定版本并锁定；保留现有后端依赖版本。Next修改前读取本期安装版本的 node_modules/next/dist/docs。自动生成next-env.d.ts的必要引用按生成物处理，手写源码仍禁止注释。浏览器可执行文件在CI显式安装，不使用passWithNoTests/skip作为缺少装置的成功路径。
