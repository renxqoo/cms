# OneAster SDK 公共操作集成

SDK 操作清单与实际 HTTP 注册表保持一致，覆盖语言默认切换、预览票据和公共内容接口。输入 schema 直接来自所属模块与应用公开的公共内容 schema，不维护第二套字段定义。

公共和预览媒体、目录索引、sitemap 使用既有 `download` 传输，返回 `{data, bytes, filename, mimeType}`。SDK 按调用方注入的文件字节上限读取响应，超限取消读取；HTTP 错误仍使用错误响应上限处理并抛出，不自动重试。PNG 和 NDJSON 均保留原字节，不尝试作为单个 JSON 解析。

原始 NDJSON 下载不代表导出已经完整或语义有效。SDK 不校验 start/item/end、序号、计数和摘要；业务调用方必须按公共导出合同完成这些验证后才能使用结果。SDK 不把返回的下载对象标为已验证数据。未设置 token 的公开读取不发送 Authorization；私有预览需显式传入预览凭据。MCP 继续排除所有 access=public 操作，即使权限发现响应包含这些操作，也不能把公开读取和预览凭据端点注册为管理工具。

验证覆盖实际 99 个注册操作与生成物一致、17 个新增操作的输入、完整 PNG 和多行 NDJSON 字节保真、匿名公开读取、文件预算拒绝，以及恶意权限发现不能使公共和预览操作进入 MCP 工具列表。目标测试先于生成器和传输分类修复运行，完整仓库门禁由整合工作区执行。
