# Collections 权限与展示一致性

本增量使用主工作区合并后的配置与存储为基线。关系展开以请求内保存的原始持久化数据执行字段读取权限，不使用 afterRead 或虚拟字段改变后的展示值放宽权限；目标集合存在关系路径读取策略时，展开查询携带与直接读取相同的关系授权范围。

集合与字段权限回调统一支持同步或异步结果，使用已有函数调用总量、期限及取消预算。读取、写入、查询字段、集合 metadata、编辑器与历史读取调用方统一 await；回调上下文复制并冻结，包含当前身份、操作、语言、原始文档及字段的稳定路径、相邻数据与最近 block。字段 validate 权限优先独立配置，省略时复用 write，保持明确拒绝越权改变的应用契约。

不保留同步权限执行旧路径。配置与 API、管理端一起切换，以行为版本、权限拒绝、回调超时及取消作为观测项；回滚恢复同一版本配置与应用，持久化字段和修订不变。

验证通过公开业务 API 覆盖列表、单文档、历史版本、关系展开的合法与拒绝结果，权限异步允许与拒绝、上下文稳定性、超时和取消后的事务释放。资产前台请求与处理 worker 将取消信号传到内容权限；资源发现与集合列表共享请求内调用预算。完整门禁与其它重数据库测试串行执行。

validate 权限保留未修改的只读原值，拒绝越权改变；写入本身继续拒绝显式提交被拒绝字段。已有文档写入与恢复传真实目标 id；创建准备阶段未分配 id 时省略，复制源的读取 id 不冒充新目标。

定向验证：关系回归修前两例失败，修后三文件十例通过；异步公开接口回归修前四例失败，修后四例通过；字段权限纯模块三文件十二例通过。独立底座后端 771 文件和 UI 基础包 63 文件类型检查通过，变更路径类型感知检查零错误与警告。此增量未执行全仓覆盖率与浏览器门禁，集成后统一串行运行。
