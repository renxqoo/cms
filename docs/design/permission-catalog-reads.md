# 权限保存后的目录读取

权限表与全局权限创建不读取端点目录。编辑既有权限时完整加载端点目录；创建权限时，用户切换到集合范围的事件触发完整目录加载，并在该弹窗关闭前保留读取需求。集合选项合并可读集合与完整端点目录中的集合键，因此缺少集合目录读取许可时仍可从端点目录取得有效回退选项。端点目录不完整时禁止停用既有权限，并提供显式重试。

创建权限和编辑名称、描述、状态只变更权限记录与审计，不改变端点定义或绑定的 id、permissionId、version。因此成功保存后刷新权限表，保留当前端点目录，不重复分页读取未变化的数据。权限状态变更仍由权限编辑流程刷新访问控制。

回归验证创建和更新后权限表显示服务器确认值、完整端点目录不重复读取，并执行原 RBAC 长旅程的开发和生产模式。保留生产 IP120/分钟、每用户每操作60/分钟的限流策略、旅程断言及首次目录依赖，不在初始化或测试旅程中重置限流桶。
