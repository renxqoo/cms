# Collections 层级与标签

状态：当前契约，2026-10-27。参考本地 Payload 的 hierarchy/tags 真实实现，保持现有集合、文档版本、关系和字段编译引擎。

## 配置与持久化

hierarchy 为集合启用单父级自关系；tags 为同一能力的标签预设，默认允许其他集合多选引用。两者互斥，父字段必须是非本地化、单值、同集合 relationship。未配置字段由注册阶段补齐，已有同名字段必须完全符合约束。父关系通过现有文档字段和版本关系表持久化，修订 CAS、统一写 fence、发布和历史恢复均沿用已有入口。

配置可指定父字段、标题字段沿用 admin.useAsTitle、独立 slug 字段或版本化 slugify、虚拟 slugPath/titlePath 字段名、树分页上限、关联集合多选限制、适用集合选项与反向 join 字段。注册时扫描真实关系构建关联集合元数据。适用集合选项保存于普通 select 字段，修改和引用都复核，不能将已经被引用的节点改为不接受该来源集合。

## 写入与读取

每次新修订都检查父链，拒绝自身、循环、跨集合父项、已归档父项与超过现有最大层级深度的结构；通用保存、复制、版本恢复和批处理使用同一检查。多个相向移动通过统一事务 fence 串行，失败整体回滚。移动操作对全部源文档与目标父链复核读取、更新和字段写入权限，携带逐文档预期修订，受编辑租约保护；没有部分成功或绕过普通内容保存的写入。

路径为虚拟字段，不保存第二份权威树。当前文档与每个祖先均按实际 mode、locale、fallback 和当前文档/字段读权读取。必要祖先或父字段不可读时两条路径均为空；标题和 slug 分别复核字段权限，对应不可读时仅该路径为空，不跳过隐藏祖先拼出错误路径。列表、详情、关系展开、资源列表和历史读取遵循相同投影，最后仍经过最终字段读权限过滤。路径投影使用请求内缓存及已有查询/展开/深度预算。标题和祖先均先执行同一异步虚拟字段与 afterRead 转换，再以原始持久化数据复核字段策略，材料化结果不能扩大读取权限。历史版本保留自身历史内容；自身快照与当前祖先组合成不可用路径时，路径为空，不拒绝读取历史。

## 产品入口

集合列表在启用配置时展示可展开、分页的树；用户可以打开节点、创建子项或用可搜索的父选择器移动单个或多个节点。展开、切换语言/模式和卸载时取消在途请求。标签集合与普通编辑器及关系多选控件协作；适用集合限制由服务端校验，前端只展示安全可读的候选和标题。页面保留键盘可访问按钮、错误反馈与当前选择。

## 演进、回滚与观测

通用能力不新增平行层级表。0015_hierarchy_validation.sql 增加有界图校验状态；0020_content_taxonomy.sql 新增标签集合和文章标签关系，保留全部 OneAster 集合及既有映射。文章 schema v1 历史快照经普通演进回填至 v2；若目标集合完全没有文档和修订，生成迁移可原子激活，存在任何历史则必须先回填再激活。应用新增标签样例集合及文章标签关系，使用现有 schema 演进生成物和真实迁移，保留原 schema 快照、回填和激活契约。部署期间停写并排空旧应用；迁移、回填和验证完成后原子切换，不同时接受两套父字段或关系格式。回滚先停写并恢复相匹配的配置、schema 快照和数据库备份；保留迁移审计，不能只删父关系修复循环。

ready 检查与迁移命令使用同一 createHierarchyIntegrityValidator。每个配置集合记录 epoch，相关当前文档指针、归档和发布槽变更使其失效，无关集合写入不触发整图扫描。扫描按页与祖先链在现有安全锁和同一内容写 fence 内执行，遵守取消、超时、SQL 与深度预算；每阶段复核 schema、动态语言源、配置签名、epoch 和扫描凭据。有效结果仅在同一 epoch 与配置下写入。扫描租约拒绝并发请求互相抢占，失败或中断后到期可重试，相关内容修复立即清除扫描租约。配置、深度和语言源改变必须重新验证；ready 不能仅凭 schema manifest 已激活接受循环或过深的旧图。

观测 invalid_input 循环/配置错误、capacity_exceeded 深度与预算、not_found 隐藏父链、forbidden 适用集合或字段权限、version_conflict 过期修订及 document_locked 租约冲突。最终验证报告列出真实测试数、覆盖率和未执行检查。
