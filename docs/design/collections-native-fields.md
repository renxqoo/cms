# 原生字段、语言读取与候选验证

## 字段定义

`slug` 保存字符串，默认必填且唯一。`useAsSlug` 指定同级来源字段，省略时读取 `title`；`slugify` 是带版本的受限异步函数，获得当前语言、主体、候选值、同级及块数据和取消信号。默认转换使用小写 ASCII、数字和短横线。来源不能生成有效值时使用集合的当前语言单数标签，再退回集合 key。

新建自动生成值时会寻找未占用的数字后缀。显式输入冲突返回字段错误。更新标题和空值自动保存保留已有 slug；复制没有显式 slug 时生成独立值。后台支持解除自动生成状态并手动编辑。唯一性仍使用统一事务保留，函数及候选查询受现有调用、时间和 SQL 预算约束。

日期字段的 `timezone` 启用同级 `${name}_tz` 选择字段。日期保存 UTC 时间点，伴随字段保存 IANA 时区；改变时区只改变显示，编辑墙上时间才转换时间点。不存在的夏令时时间返回输入错误，重复时间采用较早时间点。支持时区选项、默认值、必填和带版本的同步定义覆盖；覆盖不能改变伴随字段的身份、名称和选择类型。伴随字段继承语言和字段访问规则，参与保存、复制、发布和历史。

伴随字段由注册器递归生成，命名标签页和块也遵循相同规则。再次注册已规范化定义不会重复生成字段。启用或改变持久化字段必须更新集合 schema 版本，通过既有物理计划、回填和激活流程切换；不得只修改生成快照或让新旧 writer 混跑。回滚在停写后按已保存数据是否包含新字段决定是否先转换。

## 选择项与候选上下文

`select`、`radio` 和块字段支持固定或带版本的动态 `filterOptions`。函数接收不可变的完整候选数据、同级数据、块数据、语言和主体；返回全部、全部禁用或已声明选项的子集。对象选项保留本地化标签，重复值、未知值及无效返回均失败。块只能选择已注册块 key。最终写入复核这些约束，即使草稿关闭完整验证，也不能写入被禁止的选择项。

条件、组件动态 props 和选择项共用 `collections.previewEditor`。单候选输入用于新建、复制和普通编辑；批量输入携带每个文档的当前 revision 与同一补丁。返回共同可见字段、共同选项及一致的组件 props。任一候选无权或过期时整次请求失败。

前端按候选内容调度预览，取消被替代和已卸载页面的请求，忽略迟到结果。预览未完成或失败时禁止提交并提供重试；保留输入值供继续编辑。服务器在实际写入时再次校验。

## 独立验证

`documents.validate` 对应 `POST /v1/collections/:collection/validations`，使用独立集合及字段验证权限。新候选传 `data` 和可选语言，或者非空 `dataByLocale`；已有文档额外同时传 `id` 与 `revision`。`mode` 支持 `draft`、`publish`，默认 `publish`。

验证运行默认值、验证前钩子、完整字段规则、候选过滤、关系授权、层级约束和唯一性查询。返回 `{valid, errors}`；字段错误包含稳定路径，逐语言验证错误含语言。权限、版本及无效协议仍按统一错误契约失败。验证不会提交文档、修订、审计或任务，也不运行变更后的钩子。

## 全语言读取

文档详情、列表和版本详情支持 `locale: 'all'`。本地化字段返回语言映射；共享容器保留稳定行 ID，递归映射其中的本地化字段。展开的关系和反向 Join 分页遵循相同投影规则。历史读取使用该历史修订；发布读取使用各语言自己的发布指针。

全语言读取不自动补语言缺失值，不能同时请求非空 fallback。列表的筛选、排序、分页和数量使用集合默认语言，附加语言只读取当前 SQL 页中的文档，并逐语言复核集合和字段读取权限。内部附加语言查询使用文档 ID 排序，不依赖可能不可读的默认标题字段。

## 内联关联编辑

关联和上传选择器通过抽屉复用完整内容编辑器。显示新建和编辑操作前检查目标集合的读取、编辑器及对应写入权限；目标语言不支持当前语言时使用其默认语言。抽屉复用字段、媒体、租约、保存及发布流程，保留键盘焦点和未保存离站保护。

目标保存后通过同一字段候选查询重新检查资格，再关联到父候选。编辑已选目标保留原引用顺序，不替换父表单的未保存数据。保存成功但不再满足候选约束时，明确提示目标已保存且未关联，允许继续处理。父上下文改变、只读、取消或卸载都会取消资格查询。

## 验证归属

后端公开 API 回归位于 `content/__test__/native-slug.test.ts`、`date-timezone.test.ts`、`choice-options.test.ts`、`on-demand-validation.test.ts`、`all-locales.test.ts` 和 `editor/__test__/bulk-presentation.test.ts`。配置生成回归位于 `collections/__test__/native-config.test.ts`。前端以 `native-fields.test.tsx`、`candidate-presentation.test.ts`、`copy-field-options.test.tsx` 和 `inline-reference-editor.test.tsx` 验证实际交互、过期结果及取消。

字段写入权限在执行完整候选规则前校验。创建后固定的消息包 contractVersion、locale 和 namespace 的变更统一返回 forbidden；创建拥有写入权限但违反软件消息合同的候选返回 invalid_input。直接生效和独立发布验证均以 publish 模式执行，不提前以草稿模式调用自定义验证器。
