# 独立语言发布与发布计划

状态：实施中，2026-10-26。

集合可声明 `localizeStatus: true`，仅适用于 drafts 模式。未启用时保持文档级发布；启用时发布和撤回仅影响请求 locale，省略 locale 使用配置默认语言。公开 DTO 的 `publishedVersionId` 是所选语言的发布修订；文档 revision 仍统一 CAS，任何语言操作都会推进它。发布读取、搜索、排序、关系条件和计数必须消费同一语言的发布修订，不能因其他语言已经发布而返回当前草稿。

发布的权威记录统一存入 `content_publications(document_id,collection_id,locale,version_id)`，复合外键保护文档和修订归属。文档级模式使用 `*` 键；语言模式使用真实 locale。0014 迁移将现有指针转入文档级记录并删除旧列，不保留双写或旧列别名。启用现有集合的独立语言发布前，离线转换必须把文档级记录展开为配置的语言，验证后才启动；未完成转换时 readiness 拒绝。db:migrate 在有界事务中按当前配置展开旧文档级记录，并记录系统审计；重复执行不会重复迁移。反向切换拒绝自动折叠语言记录，需要明确人工合并和验证。

0017 为发布槽保存语言命名空间的 schema 版本，并维护按发布语言实际回退结果生成的 `content_publication_references`。原始修订引用保留历史及物理清理约束；有效发布引用只参与当前发布的保护。未发布翻译不会错误阻止归档，实际通过回退读取的引用持续受保护。每个 schema 的完成标记与投影可并存，空引用也记录完成；指针变更清除旧版本的有效投影，就绪检查拒绝缺少当前投影的发布槽。

语言重命名及删除由 schema 回填消费显式 `localeMap`，同步迁移发布槽并重建有效引用。独立发布修订不会自动合并，冲突拒绝并回滚事务；移除语言只移除其发布状态，原始历史保持不变。破坏性语言转换期间停写，旧 schema writer 在命名空间已转换时被拒绝，完成回填及 activate 后只运行新版。

各语言独立发布仅验证该语言，直接生效和文档级发布保持所有语言完整性验证。唯一保留覆盖当前修订全部语言及每个真实已发布语言的值；版本裁剪保护所有发布修订、活动修订及在途计划。归档清除全部发布记录，回收站恢复不会重新发布。历史恢复创建新编辑修订，不改动已发布语言。全局发布逐语言复核关系读取权限。固定媒体预览和下载使用同一逻辑语言及 fallback 顺序选择绑定，下载请求携带 locale/fallback；不能用其他语言的 bindingId 绕过投影与源字段、目标下载权限。

计划沿用 `content.schedulePublication`，输入增加 `action=publish|unpublish` 和 locale；默认 publish。publish 绑定当前编辑修订，unpublish 绑定所选语言的发布修订。执行时重新核验受理人的对应发布或撤回权限、原受理权限、资源谓词、预期 revision 和目标版本；任何一项改变使该项失败，不修改新版内容。任务的 discovery、详情、终态统计使用真实 action 和 locale 资格。取消沿用原计划取消接口，始终按任务载荷保存的语言重新授权；请求语言不能替换任务授权语言。列表、详情与取消均接收 locale，受理后的 Location 和后台跳转保留语言。

切换前停止全部旧 writer、维护和 CLI，执行追加迁移及必要语言转换，核对指针归属、唯一保留、任务载荷和 ready，再启动新版。旧 publication 任务载荷在迁移中改成明确 publish，删除兼容分支。回滚先停写；各语言出现不同发布版本后必须显式合并或保留新版，不能直接恢复旧指针列。该文档只定义发布协议，不授权执行生产迁移或部署。

全局发布配置 publicationLocalesField 时，有效发布引用仅索引该修订实际选中的语言。未选语言中的旧草稿引用继续作为历史物理引用保护 purge，但不阻止仅由活跃引用控制的归档。

一次性迁移入口依次执行物理迁移、各历史 schema 到当前 schema 的有界回填、覆盖校验与激活、发布语言命名空间及引用投影转换、层级完整性验证，再核对操作目录。SIGINT/SIGTERM 取消在途维护并关闭连接；每页输出处理状态，不输出正文或凭据。达到配置页数预算显式失败并保留已完成进度，可使用 content:backfill 的现有游标协议续跑后重新执行迁移。生产迁移和部署仍须单独授权。
