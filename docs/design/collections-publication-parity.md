# 独立语言发布与发布计划

状态：实施中，2026-10-26。

集合可声明 `localizeStatus: true`，仅适用于 drafts 模式。未启用时保持文档级发布；启用时发布和撤回仅影响请求 locale，省略 locale 使用配置默认语言。公开 DTO 的 `publishedVersionId` 是所选语言的发布修订；文档 revision 仍统一 CAS，任何语言操作都会推进它。发布读取、搜索、排序、关系条件和计数必须消费同一语言的发布修订，不能因其他语言已经发布而返回当前草稿。

发布的权威记录统一存入 `content_publications(document_id,collection_id,locale,version_id)`，复合外键保护文档和修订归属。文档级模式使用 `*` 键；语言模式使用真实 locale。0014 迁移将现有指针转入文档级记录并删除旧列，不保留双写或旧列别名。启用现有集合的独立语言发布前，离线转换必须把文档级记录展开为配置的语言，验证后才启动；未完成转换时 readiness 拒绝。反向切换只有各语言指针一致时可自动合并，否则要求明确人工选择。

各语言独立发布仅验证该语言，直接生效和文档级发布保持所有语言完整性验证。唯一保留覆盖当前修订全部语言及每个真实已发布语言的值；版本裁剪保护所有发布修订、活动修订及在途计划。归档清除全部发布记录，回收站恢复不会重新发布。历史恢复创建新编辑修订，不改动已发布语言。

计划沿用 `content.schedulePublication`，输入增加 `action=publish|unpublish` 和 locale；默认 publish。publish 绑定当前编辑修订，unpublish 绑定所选语言的发布修订。执行时重新核验受理人的对应发布或撤回权限、原受理权限、资源谓词、预期 revision 和目标版本；任何一项改变使该项失败，不修改新版内容。任务的 discovery、详情、终态统计使用真实 action 和 locale 资格。取消沿用原计划取消接口。

切换前停止全部旧 writer、维护和 CLI，执行追加迁移及必要语言转换，核对指针归属、唯一保留、任务载荷和 ready，再启动新版。旧 publication 任务载荷在迁移中改成明确 publish，删除兼容分支。回滚先停写；各语言出现不同发布版本后必须显式合并或保留新版，不能直接恢复旧指针列。该文档只定义发布协议，不授权执行生产迁移或部署。
